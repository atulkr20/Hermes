    Core Capabilities
    Everything a webhook needs to survive.
    🔐
    HMAC-SHA256 Signatures

    Every payload dispatches with X-Webhook-Signature. Receivers verify before business logic runs. Timing-safe comparison prevents brute-force.

    ⚡
    Exponential Backoff Retries

    5 attempts spread over immediate → 1m → 5m → 30m → 2h. Absorbs transient outages without hammering downstream systems.

    📬
    Dead Letter Queue

    After 5 failures, events are sealed with reason codes and timestamps. One API call requeues them when your endpoint recovers. Zero silent drops.

    📡
    BullMQ + Redis Engine

    Redis-backed BullMQ handles concurrency, persistence, and job visibility across worker restarts, deployments, and crashes.

    📜
    Full Attempt Logging

    Every delivery attempt is journaled to Postgres via Prisma — status code, latency, timestamp, error. Complete audit trail, always queryable.

    🏪
    Per-Merchant Isolation

    Each merchant gets a scoped HMAC secret. Toggle delivery independently. Events never bleed between tenants. Multi-merchant from day one.

    Recovery is built in.

    Hermes treats transient failures as normal. When your endpoint drops, events backoff gracefully. After 5 failures they seal into the Dead Letter Queue — preserved, traceable, and requeue-able with a single API call.
